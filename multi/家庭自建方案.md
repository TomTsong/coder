# 家庭自建 + Cloudflare Tunnel 方案

用家里的废旧电脑当服务器，手机在外通过域名连回来写代码。
**无需固定 IP、无需公网 IP、无需暴露路由器端口**，用 Cloudflare Tunnel 出站穿越。

> 适用前提：自己/小团队用，能容忍偶尔的断电断网与家宽上行带宽限制。

---

## 一、核心思路：为什么不用固定 IP

手机在外访问家里电脑，传统办法是"家里有公网 IP + 端口映射"。但这条路有两个坑：

1. 家庭宽带普遍**没有公网 IP**（CGNAT 大内网），或只有动态 IP。
2. 即便有，**上行带宽很小、且要把家里端口暴露到公网，有安全风险**。

Cloudflare Tunnel 换了一条路——**家里电脑主动出站连到 Cloudflare**，CF 把你的域名流量转进来：

```
手机（在外）──▶ Cloudflare 边缘 ──▶（出站隧道）──▶ 家里电脑
                  code.thinkers.top            192.168.1.x:8080
```

- 你**不需要**公网 IP、固定 IP、路由器端口映射
- 你**不暴露**家里的任何端口（连接是往外建立的）
- 家里电脑只要能看到外网（能出站）就行，哪怕在大内网后面

---

## 二、前提条件

| 项 | 要求 |
|---|---|
| 域名 | 你已有 `thinkers.top`（`.top` 是国际域名，可托管到 Cloudflare ✅） |
| DNS 托管 | 域名 NS 需迁到 Cloudflare（免费） |
| 家里电脑 | 一台废旧电脑/迷你主机/树莓派，装 Ubuntu 24.04 |
| 家庭宽带 | 能正常出站访问外网即可 |
| 电费/稳定性 | 常年 7×24 运行，需接受偶尔断电断网 |

> ⚠️ 关键约束需提前认清：
> 1. **上行带宽**：家宽上行常被限到几 Mbps，多人同时用会卡。
> 2. **稳定性**：停电/断网时，你在外无法重启，服务就断了。
> 3. **域名托管迁移**：`.top` 域名迁到 Cloudflare 后，解析由 CF 管理。

---

## 三、域名托管到 Cloudflare（一次性）

1. 注册/登录 [Cloudflare](https://dash.cloudflare.com/)
2. 添加站点 `thinkers.top`（选 Free 计划）
3. Cloudflare 会给你**两个 NS 地址**
4. 去你现在的域名注册商（阿里云/腾讯云）把 `thinkers.top` 的 **NS 记录改成 CF 那两个**
5. 等 DNS 生效（几分钟到几小时）

验证：`dig thinkers.top NS` 应显示 `xxx.ns.cloudflare.com`。

## 四、家里电脑装系统 + 跑 coder

### 4.1 装系统

废旧电脑刷 Ubuntu 24.04 Server（无图形界面省资源），配置好内网 + SSH，让它能上网。

### 4.2 跑多用户版初始化

把仓库 `multi/` 目录上传到家里电脑，然后：

```bash
cd multi
# 家庭自建版：不装 Caddy、不用域名 A 记录（域名交给 CF Tunnel）
bash install.sh
```

> 若不想用门卫（自己一个人用），也可以退到 `single/` 版，逻辑相同。

### 4.3 创建用户

```bash
coder-admin add alice   # 拿初始密码
```

## 五、搭 Cloudflare Tunnel（核心步骤）

### 5.1 安装 cloudflared 并登录

```bash
# 下载 cloudflared（Linux amd64）
curl -L 'https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64' \
  -o /tmp/cloudflared
sudo install -m 755 /tmp/cloudflared /usr/local/bin/cloudflared

# 登录 CF，会给你一个 URL，浏览器打开授权你的域名
cloudflared tunnel login
```

### 5.2 创建隧道

```bash
cloudflared tunnel create coder-home
# 输出隧道 UUID，记下来（形如 abc123...）
```

### 5.3 配置隧道路由

编辑 `~/.cloudflared/config.yml`：

```yaml
tunnel: <你的隧道UUID>
credentials-file: /home/你的用户/.cloudflared/<隧道UUID>.json

ingress:
  - hostname: code.thinkers.top
    service: http://localhost:8080    # 指向门卫服务（多用户版）或 ttyd（单用户版）
  - service: http_status:404
```

### 5.4 配置 DNS（CF 侧）

`config.yml` 里的 hostname 会自动在 CF 建一条 CNAME 到隧道，但你也可以手动加：

```
code.thinkers.top  →  CNAME  <隧道UUID>.cfargotunnel.com
```

### 5.5 隧道常驻

```bash
# systemd 常驻
cloudflared service install      # 自动装成系统服务
sudo systemctl start cloudflared
sudo systemctl status cloudflared   # 确认 running
```

```
https://code.thinkers.top
```

应出现登录页，输 `alice` 的密码进去，就是完整的网页终端。

## 七、与云服务器方案的关键差异

| 项 | 云服务器 | 家庭自建 + CF Tunnel |
|---|---|---|
| 固定 IP | 自带 | 不需要（CF Tunnel 代劳） |
| 月成本 | ¥60–100 | 电费 ~¥50，Tunnel 免费 |
| 上行带宽 | 对称 5–10M | 家宽上行受限，可能卡 |
| 稳定性 | 99.9% | 停电/断网即断 |
| 端口暴露 | 需防火墙 | 零暴露（出站连接） |
| 数据位置 | 云上 | 完全在自己家里 |

## 八、踩坑记录（提前规避）

1. **域名没迁到 CF 就上不了 Tunnel**：Tunnel 需要域名托管在 CF，这是硬前提。
2. **上行带宽**：先测家里上行（`speedtest`），低于 10Mbps 时网页终端多人会很卡。
3. **断电断网无人值守**：人在外无法重启。可加一个「来电自启」（BIOS 设 power on after AC loss）+ systemd 自启服务。
4. **Claude Code 出网**：家里电脑要能稳定访问 DeepSeek 接口，若家里网络对某些域名不稳，需留意。
5. **`cloudflared service install` 会读 `~/.cloudflared`**：确保以正确的用户身份配置凭据。

## 九、决策建议

| 你最看重 | 选哪个 |
|---|---|
| 省钱 + 数据完全私有 + 能容忍偶尔断 | **家庭自建 + CF Tunnel** |
| 稳定 + 随时可用 + 省心 | **云服务器**（¥60/月买稳定和带宽） |

**一句话**：家庭自建真正省下的不是"固定 IP 的钱"（那本就不该花），而是每月的云服务器租金；代价是家宽上行带宽和无人值守的稳定性。若只是自己在外随时写代码、能接受偶尔卡顿和断线，家庭自建 + CF Tunnel 是**完全可行且省钱的**。
